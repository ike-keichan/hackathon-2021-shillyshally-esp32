# hackathon-2021-shillyshally-esp32

「第2回 bitA Hackathon」で作った作品の、ハードウェアのプログラム。

> 当時の記録として残しているリポジトリです。プログラムは当時のままで、リファクタリングや修正は行っていません。

| 項目 | 内容 |

このリポジトリには、作品のうち、ハードウェアのプログラムだけが入っている。マイコンボードの ESP32 で、感圧センサーの値を読み取り、値が決めた大きさ以上になると、Wi-Fi 経由で Web API を呼び出す。

## ディレクトリ構成

| ファイル | 内容 |
| --- | --- |
| `main/main.ino` | 本体。Wi-Fi への接続、センサーの読み取り、API の呼び出し |
| `main/debug.ino` | センサーの値と、API の応答を、シリアルモニタに表示する関数 |

## 実行環境

| 項目 | 内容 |
| --- | --- |
| ボード | ESP32 |
| 部品 | 感圧センサー（32番ピンにつなぐ） |
| 開発環境 | Arduino IDE と、ESP32 用のボード定義 |

## セットアップ

`main/main.ino` の次の3つは、`*****` で伏せてある。自分の値に書き換える。

| 変数 | 内容 |
| --- | --- |
| `ssid` | Wi-Fi の SSID |
| `password` | Wi-Fi のパスワード |
| `endpoint` | 呼び出す API の URL |

## 実行方法

1. Arduino IDE で `main/main.ino` を開く。
2. ボードに ESP32 を選び、書き込む。
3. シリアルモニタを 115200 bps で開くと、センサーの値と API の応答が表示される。
